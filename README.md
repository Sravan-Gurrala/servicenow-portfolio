# ServiceNow Portfolio Projects

Hands-on ServiceNow administrative and development projects built in a Personal Developer Instance (PDI) while preparing for the Certified System Administrator (CSA) examination.

## Project Directory

### 1. [Employee Onboarding Application](./project-1-employee-onboarding/)
Service Catalog request intake form with dynamic variables, UI Policies, Client Scripts, Flow Designer automation, task orchestration, and email notifications.

### 2. [Incident Auto-Assignment System](./project-2-incident-automation/)
Automated incident management lifecycle featuring category-based assignment rules, VIP caller handling, Business Rules, Client Scripts, and SLA Definitions.

### 3. [Leave Management Scoped Application](./project-3-leave-management/)
Custom scoped application built in ServiceNow Studio containing 3 custom tables (extending Task), ACL security rules, UI Policies, and Data Policies.

### 4. [IT Asset Request Portal & Data Management](./project-4-it-asset-portal/)
Self-service Record Producers, Order Guides, CSV data imports using Import Sets and Transform Maps with Coalesce logic, and executive dashboards.
